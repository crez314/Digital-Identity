# GPU 대여 절차서

이 맥으로는 자체 호스팅 검증이 불가능하다(480×640 2초에 24분 30초, `README.md`). 판단에 필요한 숫자는
GPU를 빌려서만 얻을 수 있다. 이 문서는 **어디서 빌리고, 어떤 순서로 하고, 돈이 새지 않게 무엇을 지키는가**를 적는다.

가격·조건은 2026-09-17 기준 RunPod 공시 문서에서 확인한 값이다. 바뀔 수 있으므로 결제 전에 콘솔에서 다시 본다.

## 어디서 빌리나

| 업체 | 특징 | 판단 |
| --- | --- | --- |
| **RunPod** | 초 단위 과금, 네트워크 볼륨, HTTP 프록시로 포트 노출, ComfyUI 템플릿 | **권장.** 우리 구조(ComfyUI API를 맥에서 호출)에 그대로 맞는다 |
| Vast.ai | 같은 방식이며 더 싼 경우가 많다. 다만 가격이 공급자별로 변동하고 머신 품질 편차가 있다 | 비용을 더 줄여야 할 때 재검토 |
| Lambda Labs | 안정적이나 온디맨드 물량이 자주 없다 | 장기 예약이 필요해지면 검토 |

아래 절차는 RunPod 기준이다.

## 준비물

- 계정과 신용카드. **$10부터 충전 가능**하고, 검증 1회에는 $5면 충분하다.
- 레퍼런스 이미지 1장 (이 저장소의 `run.py`가 쓰는 `ref.png`).
- 이 디렉터리의 `runpod-setup.sh`, `workflow-vace.json`, `run.py`.

## 절차

### 1. 네트워크 볼륨을 먼저 만든다 — 순서를 바꾸면 안 된다

Storage → Network Volume → 50GB, 데이터센터 선택.

**왜 먼저인가**: 네트워크 볼륨은 **Pod을 만들 때만 붙일 수 있다.** 나중에 붙이려면 Pod을 지우고 다시 만들어야 한다.
그리고 잔액이 0이 됐을 때 **볼륨이 붙은 Pod은 정지되고 데이터가 보존되지만, 볼륨이 없는 Pod은 삭제되고 데이터를 복구할 수 없다.**
35GB짜리 가중치를 다시 받는 일을 피하려면 볼륨은 선택이 아니라 필수다.

- 마운트 위치는 Pod에서 `/workspace`다 (`runpod-setup.sh`의 기본 경로와 같다).
- 볼륨은 **데이터센터에 묶인다.** 그 데이터센터에 원하는 GPU가 없으면 쓸 수 없으므로, 볼륨을 만들기 전에
  그 DC에 L40S/A100 물량이 있는지 먼저 본다.
- 크기는 나중에 **늘릴 수만 있고 줄일 수 없다.** 14B fp16(34.7GB) + 텍스트 인코더 + VAE면 50GB로 충분하다.

### 2. Pod을 만든다

GPU 선택 → **볼륨을 만든 것과 같은 데이터센터** → 템플릿은 PyTorch 계열 → Network Volume 연결 →
HTTP 포트에 **8188** 추가.

| 용도 | GPU | 시간당 (커뮤니티 / 시큐어) |
| --- | --- | --- |
| 파이프라인 확인만 (1.3B) | RTX 4090 24GB | $0.34 / $0.74 |
| **14B fp16 검증** | **L40S 48GB** | **$0.79 / $1.09** |
| 14B + 긴 클립 | A100 80GB | $1.19 / $1.59 |

### 3. 환경을 올린다

Pod 터미널에서:

```bash
cd /workspace
# 이 저장소의 experiments/wan-local/runpod-setup.sh 를 올려서 실행한다
bash runpod-setup.sh 14b
```

ComfyUI 설치, 가중치 다운로드, 8188 기동까지 한다. **가중치 35GB 첫 다운로드에 시간이 걸리며 그동안에도 과금된다.**
한 번 받으면 볼륨에 남으므로 다음 세션부터는 없다.

레퍼런스 이미지를 `/workspace/ComfyUI/input/ref.png`로 올린다.

### 4. 맥에서 생성을 요청한다

Pod의 HTTP 프록시 주소는 `https://<POD_ID>-8188.proxy.runpod.net` 형식이다.

```bash
cd experiments/wan-local
venv/bin/python run.py \
  --server https://<POD_ID>-8188.proxy.runpod.net \
  --weights wan2.1_vace_14B_fp16.safetensors \
  --width 720 --height 960 --length 81 --steps 20
```

워크플로는 맥에서 검증한 것과 같다. 샘플러는 `euler`로 고정돼 있다(`uni_pc`는 결과가 무너진다 — `README.md`).

### 5. 결과를 우리 잣대로 채점한다

결과물을 내려받아 CREZ QC로 채점해 **Higgsfield kling의 0.711과 직접 비교**한다. 이 숫자가 이번 대여의 목적이다.

```bash
pnpm --filter @crez/worker exec tsx ../../experiments/wan-local/score-local.ts <영상.mp4> <profileId>
```

crez-ml의 디코딩은 h264를 전제로 하므로 webm은 먼저 mp4로 변환한다.

### 6. 끝나면 반드시 끈다

- **Stop** — 시간당 과금이 멈춘다. 볼륨 과금은 계속된다.
- **Terminate** — Pod을 지운다. 볼륨을 남겨 두면 가중치는 보존된다.

## 비용

검증 1회(L40S 2~3시간) 기준:

| 항목 | 금액 |
| --- | --- |
| GPU 2~3시간 | $1.6 ~ $3.3 |
| 네트워크 볼륨 50GB | 월 $3.5 (Pod을 꺼도 계속) |
| 데이터 전송 | 없음 (RunPod은 전송료를 받지 않는다) |
| **첫 검증 합계** | **약 $5** |

이후 운영으로 넘어간다면, 4090 기준 5초 클립 1건이 수 분대일 때 **건당 $0.03~0.07** 수준으로 추정된다.
현재 API는 kling 2.5 turbo pro 5초 1건에 1.25 크레딧이며, **크레딧 단가를 확보해야 비교가 완성된다.**

## 돈이 새지 않게 지킬 것

1. **끄는 것을 잊지 않는다.** 초 단위 과금이라 켜 둔 만큼 그대로 나간다. 생성이 끝났는데 Pod이 떠 있으면 낭비다.
2. **계정 지출 한도를 낮춘다.** 기본값이 **시간당 $80**이다. 이 작업에는 시간당 $2면 충분하므로 콘솔에서 내려 둔다.
3. **자동 충전(auto-pay)은 끈다.** 수동 충전이면 사고가 나도 충전액에서 멈춘다.
4. **잔액 알림을 켠다.** 잔액이 0인 채로 두면 볼륨까지 삭제될 수 있고, 그러면 가중치와 결과물이 사라진다.
5. **볼륨 없이 Pod을 만들지 않는다.** 잔액 0에서 Pod이 삭제되면 복구가 안 된다.

## 함정

- **HTTP 프록시에 100초 타임아웃이 있다.** `run.py`는 제출 후 3초 간격으로 폴링하므로 문제가 없지만,
  한 요청이 100초를 넘는 방식(동기 대기, 웹소켓 진행률)은 쓸 수 없다.
- **프록시 주소는 공개 주소다.** Pod ID로 가려져 있을 뿐 인증이 없다. ComfyUI에는 인증이 없으므로,
  주소를 아는 사람은 누구나 그 인스턴스를 쓸 수 있다.
- **실존 인물 사진을 올리는 작업이다.** 위 이유로 검증이 끝나면 Pod을 지우고 `input/`의 레퍼런스 이미지와
  결과물을 볼륨에서 삭제한다. 생체정보 취급 원칙(기술명세서 §16, §22)이 대여 인스턴스에도 그대로 적용된다.
- **볼륨은 Pod 생성 시에만 붙는다.** 빼먹으면 Pod을 지우고 다시 만들어야 한다.
- **볼륨은 데이터센터에 묶인다.** 그 DC에 원하는 GPU가 없으면 다른 GPU를 쓰거나 볼륨을 새로 만들어야 한다.
- **가중치 첫 다운로드(35GB) 동안에도 과금된다.** 다운로드만 하고 생성은 다음 세션에 하려면,
  그 시간만큼은 가장 싼 GPU로 Pod을 띄워 받아 두는 편이 싸다.
