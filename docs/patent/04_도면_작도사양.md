# 도면 작도 사양

특허 도면은 흑백 선화가 원칙이며, 각 구성요소에 도면부호를 부여한다.
도 5·도 6은 실측 데이터로 이미 작성되어 `figures/`에 있고, 나머지는 아래 사양에
따라 작도한다.

## 도면부호 체계

| 부호 | 구성 |
| --- | --- |
| 100 | 신원 일관성 평가 및 선택적 재생성 시스템 |
| 110 | 참조정보 생성부 |
| 120 | 신원 특징정보 추출부 |
| 121 | 제1 특징정보(얼굴) 추출 모듈 |
| 122 | 제2 특징정보(신체) 추출 모듈 |
| 130 | 객체 대응부 |
| 140 | 일관성 정보 산출부 |
| 150 | 기준 미달 검출부 |
| 151 | 심각도 산출 모듈 |
| 160 | 복합 점수 산출부 |
| 170 | 재생성 제어부 |
| 180 | 재검증부 |

## 도 1 — 시스템 전체 구성도

블록도. 좌측에 참조 자료 입력, 우측에 생성 영상 입력.

```
     참조 자료                      생성 영상
         │                             │
         ▼                             ▼
   ┌───────────┐              ┌───────────────┐

   │ 참조정보  │              │ ┌─────┐┌────┐ │
   │ 생성부    │              │ │ 121 ││122 │ │
   └─────┬─────┘              │ └─────┘└────┘ │
         │                    └───────┬───────┘
         ▼                            │
   ┌───────────┐                      │
   │    200    │──────────────────────┤
   │ 참조정보  │                      ▼
   │ 저장부    │              ┌───────────────┐
   └───────────┘              │      130      │  객체 대응부
                              └───────┬───────┘
                                      ▼
   ┌───────────┐              ┌───────────────┐
   │    190    │─────────────▶│      140      │  일관성 정보 산출부
   │ 기준      │              └───────┬───────┘
   │ 관리부    │                      ▼
   │           │              ┌───────────────┐
   │           │─────────────▶│  150 ┌─────┐  │  기준 미달 검출부
   └───────────┘              │      │ 151 │  │

                              └───────┬───────┘
                                      ▼
                              ┌───────────────┐
                              │      160      │  복합 점수 산출부
                              └───────┬───────┘
                                      ▼
                              ┌───────────────┐      ┌──────────┐
                              │      170      │─────▶│   210    │
```

**작도 시 강조할 점** — 180에서 170으로 되돌아가는 되먹임 경로가 이 발명의 요지이므로
명확히 표시할 것. 190(기준 관리부)이 140·150에 기준값을 공급하는 선도 표시할 것.

## 도 2 — 전체 처리 흐름도 (대표도)

```
 S100  복수 참조 자료로부터 신원 특징정보 추출
   ↓
 S110  산포 산출 → 이상치 제외 → 품질 가중 평균 → 대표 참조정보 생성
   ↓
 S200  생성 영상 표본화
   ↓
 S210  프레임별 제1 특징정보(얼굴) · 제2 특징정보(신체) 각각 독립 추출
   ↓
 S300  객체 추적 및 대응 결정
   ↓  ┌─ 유사도 < 기준값 또는 차순위와의 차 < 기준값 ─→ S310 대응 보류
   ↓
 S400  제1 지표(기준 대비) · 제2 지표(프레임 간) 산출
   ↓
 S500  판정 규칙 적용 → 최소 지속 조건 충족 여부
   ↓  ┌─ 미충족 ─→ (검출하지 않음)
   ↓
 S510  기준 미달 객체 식별정보 및 시간 구간 특정
   ↓
 S520  심각도(연속값) 및 사유 정보 산출
   ↓
 S600  복합 점수 산출 (가중합 − 감점)
   ↓
 S700  합격 여부 판정 ── 합격 ──→ S900 종료
   ↓ 불합격
 S710  종료 조건 확인 (무변화 반복 / 상한 도달)
   ↓  ┌─ 충족 ─→ S800 수동 검토 전환
   ↓
 S720  오류 유형에 대응하는 조건 변경 결정 (기적용 단계 제외)
   ↓
 S730  특정 시간 구간에 대응하는 부분만 재생성
   ↓
 S740  개선·무변화·악화 분류 및 기록
   └────────────→ S400 으로 복귀 (재검증)
```

## 도 3 — 참조정보 생성 흐름도

```
 참조 자료 1..N ─→ 특징정보 v₁..v_N, 품질값 q₁..q_N
   ↓
 단위벡터 정규화 → 품질 가중 평균 → 대표 벡터 c
   ↓
 각 자료의 거리 dᵢ = 1 − cos(unit(vᵢ), c)
   ↓
 중앙값 median(d), 중앙값 절대편차 MAD(d) 산출
   ↓
 zᵢ = 0.6745·(dᵢ − median(d)) / MAD(d)
   ↓
 zᵢ > σ 인 자료 제외 → 대표 벡터 재산출
   ↓
 산포 > 기준  ── 예 ──→ 생성 중단 (동일 객체 아닌 자료 혼입)
   ↓ 아니오
 대표 참조정보 확정 (버전 부여)
```

## 도 4 — 심각도 산출의 신호 구성도

네 신호가 각각 정규화되어 가중 결합되는 구조를 나타내는 블록도.

```
 제1 지표(얼굴) ─→ shortfall(x, θ₁) ─┐
 제1 지표(신체) ─→ shortfall(x, θ₂) ─┤
 제2 지표(얼굴) ─→ excess(d, θ₃)    ─┼─→ 가중 결합 ─→ 심각도 (0~1)
 제2 지표(신체) ─→ excess(d, θ₄)    ─┤        │
 지속시간       ─→ min(1, t/t_sat)  ─┘        └─→ 기여 신호 → 사유 정보

 ※ 신호 결측 시 해당 가중치를 나머지 신호로 재분배
```

**작도 시 강조할 점** — 상단 두 신호(기준 대비)와 중간 두 신호(프레임 간)가 서로
다른 성질임을 시각적으로 구분(예: 실선/파선 그룹)할 것. 청구항 6의 근거가 된다.

## 도 7 — 조건 변경의 단계적 결정 흐름도

```
 검출된 오류 유형
   ↓
 유형별 시작 단계 결정
   ├─ 경미한 이탈        → 단계 1 (조건화 강도 상향 + 시드 변경)
   ├─ 혼합              → 단계 2 (참조 자료 집합 교체)
   ├─ 교체 / 장시간 이탈 → 단계 3 (구간 재분할)
   └─ 반복 발생          → 단계 4 (생성 모델 전환)
   ↓
 해당 단계가 이미 적용됨? ── 예 ──→ 다음 단계로 상승
   ↓ 아니오
 조건 변경 확정 → 재생성 요청
   ↓
 (단계 > 4) ──→ 단계 5: 자동 재생성 중단, 수동 검토 전환
```

## 도 8 — 객체 대응 및 보류 판정 흐름도

```
 추적 객체 T₁..T_n , 등록 객체 참조정보 R₁..R_m
   ↓
 유사도 행렬 S[i][j] = cos(T_i, R_j) 구성
   ↓
 전역 최적 1:1 대응 결정
   ↓
 각 대응에 대하여:
   최고 유사도 < 제1 기준값 ── 예 ──→ 보류 (확정하지 않음)
   ↓ 아니오
   최고 − 차순위 < 제2 기준값 ── 예 ──→ 보류
   ↓ 아니오
   대응 확정
```
